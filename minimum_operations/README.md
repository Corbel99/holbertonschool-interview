# Minimum Operations

## Description

This project focuses on solving the **Minimum Operations** problem using Python.

The goal is to determine the minimum number of operations required to produce exactly `n` characters `H` in a text file.

The text editor starts with a single `H` and supports only two operations:

* **Copy All** — copies all the current characters.
* **Paste** — pastes the copied characters.

The challenge is to find the smallest number of operations needed to reach exactly `n` `H` characters.

For example, to obtain `9` characters:

```text
H
Copy All
Paste      → HH
Paste      → HHH
Copy All
Paste      → HHHHHH
Paste      → HHHHHHHHH
```

This requires **6 operations**.
